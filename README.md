# 雷军 LLMWiki

本项目累积对雷军、小米及其经历、决策、产品、工程、管理、商业思考与思想演变的理解。新资料用于补充、修正和连接已有理解，Wiki 随证据持续演化。

## 内容与职责

- `book-epub/` 仅保存最原始电子书载体；日常查询与引用使用 `raw/books/` 中的可读取文本。
- `raw/` 保存可读取、可核查的来源，包括访谈、演讲和公众号原文。
- `wiki/` 保存持续演化的理解；`wiki/index.md` 导航现有主题，`wiki/log.md` 记录重要维护变化。
- Git 保存文件的修改历史。

## 查询

普通查询从 `wiki/index.md` 找到相关主题页，再阅读页面；需要精确核实事实、原话、数字、日期或来源冲突时，查阅对应 `raw/` 原文。
