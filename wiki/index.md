# 阅读地图

P3 前三份来源《程序人生》、标题标为 2007 年的访谈和标题标为 2020 年的年度演讲已进入综合。当前页面仍是 Bootstrap 形态，P3 的六份来源与跨来源 Exit Gate 均未完成。

- [雷军](雷军.md)：技术兴趣、产品与市场校验、管理责任，以及金山与小米两个回顾节点上的自我定位。
- [编程](编程.md)：兴趣与实践、技术认可、产品结果、市场接受，以及个人手艺向组织工程的延伸。
- [金山](金山.md)：程序员到管理者的角色、盘古 Office 复盘、理想与生存、上市与后续关系网络。
- [小米](小米.md)：十周年自述中的创业起点、用户基础、硬件能力、增长调整与治理原则。
- [创业](创业.md)：失败、组队、具体风险、高速增长的遮蔽效应和危机中形成的新能力。
- [产品与用户](产品与用户.md)：从技术成果、市场接受到用户参与研发，以及价格承诺与质量边界。
- [工程师文化](工程师文化.md)：个人手艺、市场校验和组织探索空间之间的关系。

项目目的与阶段见 [README](../README.md)，维护纪律见 [AGENTS](../AGENTS.md)，来源检查与实际进度见 [维护记录](log.md)。
